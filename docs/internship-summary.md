# 科研实习总结

## 研究内容

本项目来自一段具身智能科研实习。前期调研了 VLA、任务规划、World Model、Memory、模仿学习、强化学习和跨任务泛化等方向，并提出六个候选研究方案。综合考虑研究问题是否明确、公开数据和模型是否可获得、现有计算资源能否支持，以及实验结果是否便于分析后，最终把问题收敛为：

> 传统任务级 Success Rate 不能解释长程机器人任务为什么失败。

研究重点不是单纯提高最终成功率，而是记录失败发生在哪一步、属于哪类动作、是否会传播，以及失败后能否恢复。

## 本人完成的工作

1. 搭建并运行 CALVIN 仿真环境和官方 MCIL 预训练模型，回放示范轨迹，检查环境、动作格式和任务成功判定。
2. 使用 Python 编写单任务评测、长程序列评测、结果汇总和动作分量对照脚本，实验结果保存为 JSON 和 CSV。
3. 对打开 LED、左移滑门和打开抽屉三类任务各测试 9 次，共 27 次；随后运行 CALVIN 标准评测集中的 100 条五步序列。
4. 设计位置、姿态和夹爪动作分量替换实验，并进行固定重试和失败后继续执行诊断。
5. 整理首次失败步骤、连续完成长度、动作偏差、恢复情况和失败截图，形成实验报告和过程级结果图。

## 主要实验结果

| 指标 | 结果 |
|---|---:|
| 打开 LED | 2/9 |
| 左移滑门 | 0/9 |
| 打开抽屉 | 0/9 |
| 五步序列完整成功率 | 0/100 |
| 第一步成功率 SR@1 | 1% |
| 平均连续完成任务数 | 0.01 步 |
| 固定重试恢复 | 0/10 |

示范轨迹能够正常回放，说明环境、动作接口和成功判定并非整体失效。进一步对照发现，自由执行时的位置动作与示范轨迹差距明显扩大；LED 任务的一个关键步骤中，示范动作给出负的夹爪控制值，而模型给出正值，导致夹爪没有按需要闭合。

现有结果支持：闭环位置偏移是三类任务共同的直接失败表现，部分任务还存在夹爪控制方向不一致的问题。任务最终为零分，并不等于环境或模型完全不能工作，也无法单独说明失败原因。

## 一次具体的排错过程

100 条长程序列几乎都在第一步失败时，最初怀疑仿真环境或动作接口配置有误。排查时先回放真实示范，确认相同环境中的动作可以触发成功判定；随后运行三类单任务，验证模型至少在 LED 任务中能得到非零成功率；最后逐项替换位置、姿态和夹爪动作，并比较自由执行与示范状态下的动作偏差。

这组实验排除了“环境完全失效”的解释，并把问题进一步定位到闭环执行产生的位置偏移和部分任务的夹爪控制差异。

## 研究局限

- 只测试了一个公开 MCIL 检查点，尚未加入第二个基线模型。
- 使用约 1.3 GB 的 debug 数据，而不是完整 CALVIN 数据集。
- 单任务重复次数较少，结论仍需扩大样本验证。
- 推理主要在 CPU 上完成，没有进行真实机器人实验。
- 当前结论只适用于本项目的仿真环境、公开权重和实验设置。

后续可以加入第二个公开基线，扩大单任务测试次数，并将失败位置、动作类型、传播和恢复整理成统一的过程级评测指标。
